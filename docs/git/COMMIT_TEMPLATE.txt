# type(scope): mô tả thay đổi cụ thể
# Ví dụ: docs(git): bổ sung workflow và mẫu pull request
# Type: feat | fix | docs | refactor | test | chore
#
# Viết message thật trên các dòng KHÔNG có dấu #.
# Với thay đổi nhỏ, một tiêu đề rõ cùng thông tin kiểm tra có thể đã đủ.
#
# Lý do / vấn đề:
# - Điều gì cần thay đổi và vì sao?
#
# Thay đổi:
# - Hành vi hoặc nội dung sau thay đổi.
#
# Kiểm tra:
# - Đã kiểm bằng gì, kết quả; chưa chạy phần nào và lý do nếu liên quan.
#
# Ảnh hưởng / tham chiếu (chỉ giữ khi cần):
# - Schema, config, model, API hoặc giới hạn cần reviewer biết.
# - Dẫn issue hoặc evidence dùng chung; không dẫn task chỉ tồn tại local.
#
# Không ghi mật khẩu, token, chuỗi kết nối, dữ liệu cá nhân hoặc kết quả bịa.
# Không mô tả scaffold/tài liệu như pipeline/model đã chạy hoặc gate đã đạt.
